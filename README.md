# GuruSetu Bihar — Final Professional Demo

Run with `python -m http.server 8000`, then open `http://localhost:8000`.

Flow: Landing → Principal Registration → District → School Search → Verification → Details → Admin Approval → Principal Login/Dashboard → Teacher Registration → Principal Approval → Teacher Login/Dashboard → Chapter AI tools.

Admin: `admin@gurusetu.local` / `admin123`
Demo Teacher: `teacher@gurusetu.local` / `teacher123`

This is an offline/local presentation demo. School data and approvals are simulated locally; real UDISE, DIKSHA, AI and WhatsApp/SMS APIs are not connected.


## Teacher AI demo (offline)
The Teacher Workspace includes a local, rule-based AI simulation for the presentation:
- Simple explanations and everyday examples
- Lemon/example prompts
- Teaching approach
- Quick quiz
- Classroom activity
- Experiment idea
- PPT outline
- Lesson plan
- Mind map
- 30–40 second video storyboard
- Local PDF/image selection demo
No external AI API key is required for this demo. Replace `aiAnswer()` with a production AI API later.
